# Virtual Chemistry Laboratory
## Teacher presentation — Egypt, academic year 2026–2027

### Project idea
A 2D interactive virtual chemistry laboratory built with Godot 4.3+ and GDScript. It helps learners inspect matter, use a guided virtual demonstration and connect visible observations with scientific explanations.

### What a teacher can show
1. Open the welcome screen and choose **Start Classroom Demo** or **Teacher Mode**.
2. Select a grade profile: Prep 1, Prep 2, Prep 3, Senior 1 or Senior 2.
3. Open the Teacher Guide to see a grade-aware preview, learning goals, teacher prompts, material explanations and sources.
4. Open the Library and inspect the water and table-salt classroom materials.
5. Select the beaker and use the Inspector to review contents and observations.
6. Use the read-only periodic-table reference to explore the 118 element names and symbols.

### Learning value
- Makes the difference between a substance, a mixture and a solution easier to discuss.
- Connects visible observations to particle-level explanations.
- Helps students distinguish a physical process from a chemical reaction.
- Encourages teachers and students to question the assumptions and limitations of a scientific model.

### Classroom demo scope
The guided classroom setup uses water and sodium chloride. The learning guide also explains safe reference concepts such as saturation and changes of state. Other reference records are not presented as classroom reagents and do not receive operational experiment instructions.

### Curriculum evidence

### Technology
Godot 4.3+, GDScript, JSON-based content definitions, a separation between simulation logic and UI, and static/headless validation scripts.

### Verification status
Static validators cover project structure, curriculum metadata, the 118-element reference records, teacher preview data and classroom demo material boundaries. The project still requires a Godot editor/headless run and a human visual check before it should be described as fully verified for classroom deployment.
