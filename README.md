# Chemistry Lab 2D

A Godot-based chemistry learning and simulation project.

## Contents
- `scenes/` game and UI scenes
- `scripts/` simulation, UI, and core logic
- `data/` chemistry, reaction, equipment, curriculum, and setup data
- `tests/` validation and regression checks
- `docs/` architecture and development notes

## Getting started
Open the project in Godot 4.x and run the main scene from `scenes/main.tscn`.
